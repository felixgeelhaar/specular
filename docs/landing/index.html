// Capabilities

Enterprise-Grade AI Governance

Everything you need to run AI-powered development at scale with confidence.

Policy Enforcement

Define what AI can and cannot do. Image allowlisting, resource limits, and cryptographic approvals for every action.

Drift Detection

Multi-layer validation ensures spec, plan, and code stay aligned. SARIF reports integrate with GitHub Security scanning.

Docker Sandboxing

All AI execution happens in isolated containers with resource limits, network controls, and no host access.

Multi-LLM Routing

Intelligent routing across Ollama, OpenAI, Anthropic, and Gemini. Optimize for cost, latency, or capability.

Audit Trails

Cryptographic attestations with ECDSA signatures. Complete trace logging for compliance and debugging.

CI/CD Integration

GitHub Action included. Run drift checks on every PR, gate deployments on policy compliance.

Install in Seconds

Available on all major platforms. Choose your preferred method.

Homebrew
brew tap felixgeelhaar/specular && brew install specular
Docker
docker pull ghcr.io/felixgeelhaar/specular:latest
Binary
curl -sSL https://specular.dev/install.sh | sh
Go Install
go install github.com/felixgeelhaar/specular@latest
